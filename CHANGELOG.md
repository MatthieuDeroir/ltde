## [0.1.0] - 2025-10-23

### Added
- Next.js 15 project initialization with TypeScript strict mode
- Tailwind CSS + Radix UI setup
- Prisma + SQLite configuration with initial User model
- Jest + Testing Library setup with example test
- ESLint + Prettier configuration
- Husky pre-commit hooks with lint-staged
- Project structure (app/, components/, core/, server/, lib/, hooks/, types/)
- Initial documentation (README, CHANGELOG, ROADMAP)
- Git repository initialization with main and dev branches

### Technical Details
- **Stack**: Next.js 15.5.6, React 19.2.0, TypeScript 5.9.3
- **Database**: Prisma 6.18.0 + SQLite
- **Testing**: Jest 30.2.0 + Testing Library
- **UI**: Radix UI + Tailwind CSS 3.4.18
- **Package Manager**: pnpm 10.13.1
